# Canvas AI

Веб-интерфейс AI-бота для генерации редактируемых макетов в Figma.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта:

```bash
python3 -m http.server 4173
```

Сейчас генерация работает в demo-режиме. Для подключения Cloudflare Worker замените обработчик `generate` в `app.js` на запрос к вашему API, а ответ Worker используйте для заполнения `resultTitle` и `openButton.href`.
